# Counter App

A simple and interactive Counter App built using **HTML, CSS, and JavaScript**.

The application allows users to increase, decrease, and reset the counter value using interactive buttons.

## 🚀 Features

- ➕ Increase counter value
- ➖ Decrease counter value
- 🔄 Reset counter to zero
- ⚡ Instant UI updates
- 📱 Simple and responsive design

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive layout
- **JavaScript** – Counter logic and DOM manipulation

## 🧠 JavaScript Concepts Practiced

- Variables
- DOM Manipulation
- `getElementById()`
- Event Listeners
- Functions
- Increment (`++`)
- Decrement (`--`)
- `textContent`
- Event Handling
